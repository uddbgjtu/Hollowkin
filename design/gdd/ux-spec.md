> **文档类型**：UX 规格（Canonical for Phase 5 实现）

## 0. 设计原则

1. **全功能键盘可达**：所有主操作须可用键盘或鼠标完成，且有可重映射键位；不依赖触屏手势。
2. **信息密度高、弱图标、政务式清晰**：这是主理人既定审美（源自软件住房保障项目的正式规范），即**排版规整、标签明确、少用装饰性图标、状态靠文字+形状双编码**，但**不套用公文配色**——游戏仍用美术圣经 §2.2 母库。
3. **确定性优先**：UI 不依赖随机；动画/布局可种子复现（ADR-5）。
4. **可访问性 Basic 强制**：键鼠可操作目标 ≥24×24px + 键盘可聚焦、双编码、色盲安全、字号 ≥14px（见引用文档 §3）。

## 1. 设备与目标

- **平台**：Windows Desktop（PC 单平台）；移动端已彻底放弃（ADR-6）。
- **逻辑分辨率基准**：**1280×720 横屏（@1x）**，整数倍缩放（2× / 3×）护 ADR-4 像素资产；禁止非整数缩放。
- **主操作区**：横屏单屏内可达；技能键位与 HUD 布局以「不遮挡战场」为准，不再受拇指扇形区约束。
- **窗口 / DPI**：支持窗口与全屏切换、高 DPI 按整数倍放大；无刘海 / 系统手势条安全区约束。

## 2. 核心界面流（信息架构）

```
主菜单(MainMenu)
   ├─ 继续 / 新游戏
   ├─ 设置(Settings)            [非阻断·上移]
   └─ 图鉴(Bestiary)            [非阻断·上移]
        │
        ▼
探索总览(Overview)  ── 地牢入口、当前层、资源概览、灵囊/灵脉快捷入口
   ├─ 进入地牢 → 地牢探索(DungeonExplore)
   │       ├─ 遇敌 → 战斗(Battle)
   │       ├─ 拾取/互动物（形状双编码提示）
   │       └─ 层间落盘(Save, ADR-1)
   ├─ 灵囊(Pouch)               [底部 Tab]
   ├─ 灵脉图谱(SpiritVein)       [底部 Tab]
   └─ 营地/庇护所(Sanctuary)     [Boss 后解锁或中途回城]
```

**固定 Tab 栏**（横屏底部或侧边，键鼠 / 键位可达）：`[总览] [灵囊] [灵脉] [地图]` 四槽，每槽点击区域 ≥24×24px 且可用数字键直达，间距 ≥8px；Tab 热区仍走 `InputQueue` 冷却豁免（Epic F 实现不变）。

## 3. 主屏线框要点

### 3.1 战斗屏（Battle）— 最高频、最重可达性
- **下半屏**：4 个灵兽技能键（数字键 1–4 + 鼠标可点，点击区域 ≥24×24px），+ 1 个"防御/跳过"键（Space）。
- **上半屏**：敌我血条 / 状态图标（形状双编码：减益=三角警示+紫、陷阱=锯齿框+琥珀、可互动物=圆角高亮+青绿）。
- **低血量提示**：心形闪烁 + 屏幕边缘红框脉冲（不只变红，见可访问性 §3.4）。
- **冷却/禁用**：置灰 + 锁形图标 + 环形遮罩。
- **状态机**：`回合开始→玩家输入(帧末输入队列,ADR-2)→AI tick(定步长10Hz,ADR-3)→结算→回合结束`（不变）。

### 3.2 灵囊屏（Pouch）
- **三栏**：灵兽 / 符文 / 物资（顶部分段控件，点击区域 ≥24×24px，Tab 键可切换）。
- **灵兽格**：显示 slug 对应像素立绘（24×24 视觉，点击区域 ≥24×24px）+ 数量角标（ENG-2 裁定：重复灵兽 = +1 计数，角标显示 `×N`）。
- **左键 / 右键**：查看详情；**拖拽**：装备/弃用（落点 ≥24×24px），并提供键盘等价操作。

### 3.3 灵脉图谱屏（SpiritVein）
- **节点**：视觉 44px，点击区域 ≥24×24px，方向键可遍历节点（ADR-6 已废止触控 48px 下限）。
- **连接**：已激活路径高亮（青绿），未激活灰；节点状态用形状（锁=未解锁、星=已点）而非仅亮度。
- **缩放/平移**：滚轮缩放 / 中键拖拽平移，或边缘按钮；键盘 +/- 等价。

### 3.4 探索总览（Overview）
- 顶部：当前层 / 种子 / 资源计数（文字标签，非纯图标）。
- 中部：进入地牢主按钮（≥24×24px，Enter 可触发）。
- 底部：固定 Tab 栏。

## 4. 键鼠操作映射

| 操作 | 用途 | 备注 |
|---|---|---|
| 左键点击 | 确认 / 选择 / 技能 | 点击区域 ≥24×24px，键盘可聚焦 |
| 右键 / 长按 | 详情 / 上下文菜单 | 提供键盘等价键（如 I / Esc） |
| 左键拖拽 | 装备 / 弃用 / 移动 | 落点 ≥24×24px；方向键 + Enter 等价 |
| 滚轮 | 翻页 / 灵脉图谱缩放 | 键盘 +/- 等价 |
| 数字键 1–4 / WASD | 技能 / 8 向移动 | 全键位可重映射 |

**输入队列**：PC 键鼠事件经适配层转 `{"position", "touch_id": 0}` 同构字典，帧末统一入队处理（ADR-2），避免逐事件打断确定性 tick；队列结算语义不变。

## 5. 可访问性对照（Basic 红线落地）

| 红线 | 本规格落点 |
|---|---|
| 键鼠可操作目标 | 点击区域 ≥24×24px + 全功能键盘可达 / 键位可重映射（§3 / §4） |
| 双编码 | 敌我/状态靠形状+色相（§3.1、§3.3） |
| 色盲安全 | 危险红 `#FF4D4D` 配心形/红框；毒绿 `#A6FF4D` 仅作辅助（可访问性 §3.3） |
| 字号 ≥14px | 正文 ≥14px、标题 ≥18px；长文本滚动 |
| 非色彩提示 | 低血/禁用/陷阱均有形状提示（§3.1） |

## 7. 验收标准（进入 Phase 5 前主理人签字项）

- [ ] 全功能键盘可达性核验：核心操作 100% 有键位或键鼠等价路径，键位可重映射。
- [ ] 四主屏线框经认可，标签均为文字（弱图标）。
- [ ] 战斗屏状态机与 ADR-2/ADR-3 一致。
- [ ] 可访问性 §5 五项在 CVD 模拟下不丢信息。
