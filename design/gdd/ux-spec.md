# UX 规格 / UX Specification（单手触屏）

> **文档类型**：UX 规格（Canonical for Phase 5 实现）
> **归属**：design-strategist 起草，主理人签发，美术/工程/QA 共用
> **引用**：`docs/accessibility-requirements.md`（Basic 红线）、`docs/architecture/architecture-doc.md`（InputArbiter / Combat / Pouch / SpiritVein / Save）
> **版本**：v1.0 · 未 git commit。

## 0. 设计原则

1. **单手拇指可达**：所有主操作落在屏幕下 1/3 的"拇指热区"，非主操作（设置、图鉴）可上移但非阻断。
2. **信息密度高、弱图标、政务式清晰**：这是主理人既定审美（源自软件住房保障项目的正式规范），即**排版规整、标签明确、少用装饰性图标、状态靠文字+形状双编码**，但**不套用公文配色**——游戏仍用美术圣经 §2.2 母库。
3. **确定性优先**：UI 不依赖随机；动画/布局可种子复现（ADR-5）。
4. **可访问性 Basic 强制**：触控命中区 ≥48px、双编码、色盲安全、字号 ≥14px（见引用文档 §3）。

## 1. 设备与目标

- **平台**：iOS / Android，竖屏优先，单手握持。
- **逻辑分辨率基准**：720×1280（@1x），按 DPR 缩放。
- **拇指热区**（竖屏，右利手默认、可镜像给左利手）：屏幕底部高 ~40% 的扇形区；核心确认/技能键置于该区右下 1/4。
- **安全区**：顶部状态条避开刘海；底部操作条避开系统手势条。

## 2. 核心界面流（信息架构）

```
主菜单(MainMenu)
   ├─ 继续 / 新游戏
   ├─ 设置(Settings)            [非阻断·上移]
   └─ 图鉴(Bestiary)            [非阻断·上移]
        │
        ▼
探索总览(Overview)  ── 地牢入口、当前层、资源概览、灵囊/灵脉快捷入口
   ├─ 进入地牢 → 地牢探索(DungeonExplore)
   │       ├─ 遇敌 → 战斗(Battle)
   │       ├─ 拾取/互动物（形状双编码提示）
   │       └─ 层间落盘(Save, ADR-1)
   ├─ 灵囊(Pouch)               [底部 Tab]
   ├─ 灵脉图谱(SpiritVein)       [底部 Tab]
   └─ 营地/庇护所(Sanctuary)     [Boss 后解锁或中途回城]
```

**底部固定 Tab 栏**（拇指热区）：`[总览] [灵囊] [灵脉] [地图]` 四槽，每槽命中区 ≥56×56px，间距 ≥8px。

## 3. 主屏线框要点

### 3.1 战斗屏（Battle）— 最高频、最重可达性
- **下半屏**：4 个灵兽技能键（56×56px 圆角方块，置于拇指热区），+ 1 个"防御/跳过"键。
- **上半屏**：敌我血条 / 状态图标（形状双编码：减益=三角警示+紫、陷阱=锯齿框+琥珀、可互动物=圆角高亮+青绿）。
- **低血量提示**：心形闪烁 + 屏幕边缘红框脉冲（不只变红，见可访问性 §3.4）。
- **冷却/禁用**：置灰 + 锁形图标 + 环形遮罩。
- **状态机**：`回合开始→玩家输入(帧末输入队列,ADR-2)→AI tick(定步长10Hz,ADR-3)→结算→回合结束`。

### 3.2 灵囊屏（Pouch）
- **三栏**：灵兽 / 符文 / 物资（顶部分段控件，命中区 ≥48px）。
- **灵兽格**：显示 slug 对应像素立绘（24×24 视觉，命中区 ≥48）+ 数量角标（ENG-2 裁定：重复灵兽 = +1 计数，角标显示 `×N`）。
- **长按**：查看详情；**拖拽**：装备/弃用（拖拽落点命中区 ≥48px）。

### 3.3 灵脉图谱屏（SpiritVein）
- **节点**：视觉 44px，命中区 ≥48px（可访问性 §3.2 澄清）。
- **连接**：已激活路径高亮（青绿），未激活灰；节点状态用形状（锁=未解锁、星=已点）而非仅亮度。
- **缩放/平移**：双指或边缘按钮（按钮 ≥48px），保证单手可触达中心节点。

### 3.4 探索总览（Overview）
- 顶部：当前层 / 种子 / 资源计数（文字标签，非纯图标）。
- 中部：进入地牢主按钮（≥64px，置于热区）。
- 底部：固定 Tab 栏。

## 4. 手势与操作映射

| 手势 | 用途 | 备注 |
|---|---|---|
| 点按(tap) | 确认/选择/技能 | 命中区 ≥48px |
| 长按 | 详情/上下文菜单 | 阈值 350ms，震动反馈(可选) |
| 拖拽 | 装备/弃用/移动 | 落点 ≥48px |
| 滑动 | 翻页/关闭面板 | 边缘 8px 防误触 |
| 双指捏合 | 灵脉图谱缩放 | 单手可改用边缘按钮 |

**输入队列**：触屏事件在帧末统一入队处理（ADR-2），避免逐事件打断确定性 tick。

## 5. 可访问性对照（Basic 红线落地）

| 红线 | 本规格落点 |
|---|---|
| 触控 ≥48px | 所有可点元素命中区 ≥48px（§3） |
| 双编码 | 敌我/状态靠形状+色相（§3.1、§3.3） |
| 色盲安全 | 危险红 `#FF4D4D` 配心形/红框；毒绿 `#A6FF4D` 仅作辅助（可访问性 §3.3） |
| 字号 ≥14px | 正文 ≥14px、标题 ≥18px；长文本滚动 |
| 非色彩提示 | 低血/禁用/陷阱均有形状提示（§3.1） |

## 6. 与架构模块映射

| UX 区域 | 架构模块 | 说明 |
|---|---|---|
| 输入/手势 | InputArbiter | 帧末输入队列、手势→意图 |
| 战斗屏 | Combat + SpiritAI | tick 预算(ADR-3)、状态机 |
| 灵囊屏 | Pouch + StatBlock | +1 计数(ENG-2)、C1 契约 |
| 灵脉屏 | SpiritVein | 节点/连边数据 |
| 总览/落盘 | Save | 层间落盘(ADR-1) |
| 所有像素 UI | AssetPipeline | ADR-4 后处理+校验 |

## 7. 验收标准（进入 Phase 5 前主理人签字项）

- [ ] 单手可达性热力图：核心操作 100% 落在拇指热区。

- [ ] 战斗屏状态机与 ADR-2/ADR-3 一致。
- [ ] 可访问性 §5 五项在 CVD 模拟下不丢信息。
