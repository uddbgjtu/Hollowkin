## 0. 通用规格（几何萌系 · 对齐美术圣经）
- **骨架**：圆角矩形躯干 + **三角耳 / 角 / 尾**作特征识别（★ 原创改造点，区别于宝可梦具体轮廓）。大头身比 Q 版，表情 2–3 像素眉眼。
- **像素单元**：主角驯导者 / 主要灵兽 **24×24**；小灵兽 16×16；BOSS 32~48。（美术圣经 §5）
- **描边**：1–2px 深描边（24×24 用 2px），取 `#1A1C2C`，方向一致**左上受光、右下阴影**。（美术圣经 §5）
- **调色板**：每只灵兽取 **≤6 主色 + 描边/高光**；所属场景（上层/中层/Boss 深层）整体 **≤16 色**。（美术圣经 §2.2 / §5）
- **帧率**：待机/行走 4–6fps 手作低帧。（美术圣经 §5）
- **阵营形状编码**：友方/可驯服 = 圆润稳定剪影；敌方 = 尖锐/不对称/三角刺（见 §5）。（美术圣经 §3）

## 1. 主角参照（非灵兽）
- **驯导者「灯童」**：小斗篷（梯形轮廓）+ 灵囊挂饰（腰侧小袋）+ 圆顶帽；**无**三角耳/角/尾。配色：暖橙 `#FF8C42` + 奶白 `#F4E4C1` + 陶土棕 `#A56A43`（灵囊）+ 暮蓝 `#2B2F4A`（斗篷暗部）。
- 作用：作"人类"基准。灵兽均带兽耳/角/尾，天然与主角区分；本集确保灵兽彼此不撞型。
- **实体 slug**：`tamer`（资产/代码唯一引用，如 `char_tamer_24`；即 Phase 3 像素资产后处理与 Godot 导入命名源）。

## 2. 四只 MVP 灵兽（关键 / 可驯服）

### 2.1 苔背 Mossback — 坦克 / 前排承伤
- **三角特征**：耳 2 / 朝外上方（头顶两侧）；角 0；尾 0（**圆短尾，作区分轴**）。
- **配色阵营**：上层「晨雾青绿 + 暖黄光斑」；主色 `#7BC9B0` 晨雾青绿 + `#5FD35A` 草绿 + `#FFD23F` 暖黄点缀 + `#A56A43` 苔石 + 描边 `#1A1C2C` + 高光 `#F4E4C1`。
- **剪影辨识**：双外扩耳 + 无角无尖尾 → 四兽中最"圆润"的轮廓。
- **像素**：24×24，2px 描边。
- **实体 slug**：`mossback`（资产/代码唯一引用，如 `char_mossback_24`；即 Phase 3 像素资产后处理与 Godot 导入命名源）。
- **图鉴占位**：*"背覆苔石的地窟守护者，以厚甲承伤著称。"*（待 GDD 锁定后回填：承伤机制 / 技能 / 数值）

### 2.2 焰角 Emberhorn — 火系输出
- **三角特征**：耳 0（弱化小圆耳）；角 1 / 居中向前（短锐角）；尾 1 / 朝右（尖三角）。
- **配色阵营**：中层「暮紫 + 琥珀」取琥珀/橙段；主色 `#D98E32` 琥珀 + `#FF6A2C` 熔岩橙 + `#FFD23F` 暖黄 + `#7A5E9E` 暮紫暗部 + 描边 + 高光。
- **剪影辨识**：独角 + 右向尖尾 → 攻击性剪影。
- **像素**：24×24，2px 描边。
- **实体 slug**：`emberhorn`（资产/代码唯一引用，如 `char_emberhorn_24`；即 Phase 3 像素资产后处理与 Godot 导入命名源）。
- **图鉴占位**：*"额生炎角的小型灵兽，喷吐灼烧持续伤害。"*（待 GDD 锁定后回填：灼烧 DoT / 技能 / 数值）

### 2.3 霜铃 Frostling — 控制 / 辅助
- **三角特征**：耳 2 / 朝下（垂耳）；角 0；尾 2 / 上分叉（双尖三角）。
- **配色阵营**：中层「暮紫 + 琥珀」取暮紫段；主色 `#7A5E9E` 暮紫 + `#3FA7FF` 天空蓝 + `#2EC4B6` 青绿 + `#F4E4C1` 霜高光 + 描边 + 高光。

## 3. 三角特征差异表（剪影唯一性自检）
| 实体 | 耳（数/向） | 角（数/向） | 尾（数/向） | 额外三角 | 主色子集 | 实体 slug |
|---|---|---|---|---|---|---|
| 苔背 | 2 / 外上 | 0 | 0（圆） | — | 上层·青绿 | `mossback` |
| 焰角 | 0 | 1 / 中前 | 1 / 右 | — | 中层·琥珀 | `emberhorn` |
| 霜铃 | 2 / 下 | 0 | 2 / 上分叉 | — | 中层·暮紫 | `frostling` |
| 雷隼 | 1 / 后 | 0 | 1 / 后上 | 尖喙 | 上层·暖黄 | `voltsprite` |
| 主角 | 0（无兽耳） | 0 | 0 | 斗篷/灵囊 | 中性布色 | `tamer` |

**唯一性结论**：四灵兽两两之间至少在两个三角轴（耳/角/尾/额外）上不同，且与主角无兽耳/角/尾 → **几何萌系剪影唯一性自检通过**。暖色同组的焰角（琥珀）与雷隼（暖黄）靠"独角右尾" vs "单后耳+后上尾+尖喙"的**形状差异**区分，满足双编码（不依赖配色）。

### 4.1 审计结论（几何萌系剪影唯一性 + ≤16 色适配）
**审计方法**：对 4 只灵兽逐只执行第 6 节模板——比较耳/角/尾/额外三角四轴与所有其他实体（含主角）的差异；并核算单兽色数（目标 ≤8）与所属场景色数（≤16）。输入即 design-strategist 起步集（#5），未另起设计。

**逐只结果**
| 灵兽 | 剪影唯一性 | ≤16 色 | 结论 |
|---|---|---|---|
| 苔背 | 与焰角/霜铃/雷隼各 ≥2 轴不同；与主角无兽耳/角/尾 | 单兽 6 主色；上层场景 9/16 | ✅ 通过 |
| 焰角 | 与苔背(耳/角/尾)、霜铃(全异)、雷隼(耳/角/尾/喙)均 ≥2 轴不同 | 单兽 6 主色；中层场景 7/16 | ✅ 通过 |
| 霜铃 | 与苔背(耳向/尾)、焰角(全异)、雷隼(耳/尾/喙)均 ≥2 轴不同 | 单兽 6 主色；中层场景 7/16 | ✅ 通过 |
| 雷隼 | 与苔背/焰角/霜铃均 ≥2 轴不同；额外尖喙强化区分 | 单兽 5 主色；上层场景 9/16 | ✅ 通过 |

**总体结论**
- **撞型风险：无**。四兽两两至少两个三角轴不同，且与主角天然区分（主角无兽耳/角/尾）。
- **超色风险：无**。两层场景色数均 ≤16（上层 9、中层 7），单兽 ≤6 主色，全部取自美术圣经 §2.2 母库。
- **双编码校验**：焰角(琥珀)与雷隼(暖黄)同属暖色，已靠"独角右尾" vs "单后耳+后上尾+尖喙"形状差异区分，不依赖配色 alone，满足 Basic 双编码（对齐 `docs/accessibility-requirements.md` 3.1）。
- **锁定状态**：§3 三角特征差异表（含实体 slug 列）**即锁定版**，Phase 2 补 5–8 只时须用第 6 节模板复跑并维持唯一性。

## 5. 敌对剪影编码规则（供 Phase 2 扩展）
- **敌方通用语言**（美术圣经 §3）：尖锐、不对称、带三角刺/角（锯齿、倒三角、多足、悬浮核心）；**不使用**友方的圆润稳定轮廓。
- **双编码**：敌方除配色（红/紫/熔岩橙）外，必须有形状标识（如倒三角轮廓、锯齿边缘），确保色盲安全。
- *示例（非锁定，待 Phase 2 补）：* 噬影蛞 — 角 2 / 朝下（攻击性）、尾 1 / 右、无耳（尖刺）、配色暮紫 `#7A5E9E` + 危险红 `#FF4D4D`。该示例仅演示编码规则，不计入 MVP 4 只。
