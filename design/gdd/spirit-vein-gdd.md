# 灵脉图谱 GDD（Spirit Vein / 天赋）
> 版本 v0.1 · MVP（Vertical Slice）· 作者 文策渊 · 关联《概念文档》《美术圣经 v0.2》
> 原创红线：★ 灵脉图谱替代 WoW 天赋树，节点为「灵脉」主题、命名/布局全原创，严禁复制魔兽资产。

---

## 1. 概述与目标
- **系统定位**：★ 替代 WoW 天赋树的「永久成长图谱」，元进度中枢。主角「灵脉」提供基础盘与技能解锁。
- **服务设计支柱**：**P3 · 死亡不是惩罚，是节奏** —— 死亡 → 回庇护所 → 激活节点 → 下一轮更强；保证失败感不吞噬继续动机（无硬通货清零、无时间惩罚）。
- **MVP 范围**：1 条图谱雏形（径向/树状分支）+ 永久货币（灵烬 `ember_eternal`）。

---

## 2. 核心机制
1. **节点激活** —— 消耗 `ember_eternal` 激活灵脉节点；有前置依赖（需先激活父节点）。
2. **节点类型**：
   - `MODIFY_STAT`：永久修正主角/全队基础属性（如 +ATK 5%）。
   - `UNLOCK_SKILL`：解锁额外手动技能槽 / 灵兽技能池扩展（MVP 仅解锁第 2 技能或灵兽池扩展；灵兽池以 provisional 4 只 `mvp-beast-silhouette.md` 为输入，审计后见 `mvp-spirit-bestiary.md`）。
   - `GRANT_START`：开局资源（如初始符文 / 额外灵兽蛋）。
3. **图谱布局** —— 径向分支，节点大小表层级；未激活陶土棕 `#A56A43`，已激活暖橙 `#FF8C42` + 外发光（美术圣经 §4）。
- **触屏映射**：节点视觉直径 44px（保留视觉语言，美术圣经 §4），**触控命中区 ≥48×48px**（透明 padding / 命中半径 48px，a11y §3.2），点按激活（消耗确认弹窗防误触）；图谱可平移/缩放（双指，非战斗时）。

---

## 3. 数据模型
- **节点**：`{ node_id, pos(x,y), tier, type, effect, cost(ember), prereq: [node_id] }`
- **图谱**：单条主线 + 2 分支（MVP 约 12–16 节点）。
- **永久货币**：`ember_eternal`（int，上限 99999）。
- **应用快照**：进入地窟时，由「灵脉修正后的基础属性」生成 run 起始属性（见冲突 C1 / 契约）。

---

## 4. 交互与操作
- 图谱视图：节点视觉 44px（命中区 ≥48×48px，a11y §3.2），节点间距 ≥8px 防热区重叠；连线 2px 发光符文线（§4）；已激活段用 `#FFD23F`。
- 点按节点 → 弹窗显示效果 + 消耗 → 确认激活（防误触双步，呼应 Basic）。
- `ember` 不足：节点显示锁定（锁形 + 灰色），非仅变灰。

---

## 5. 状态机/流程
```
[庇护所] → [灵脉图谱] 查看 / 激活节点（消耗 ember）
   → [配置应用] 生成 run 起始属性快照
   → [进入地窟]（战斗 / 灵囊读取该快照）
[死亡结算] → coin_temp 转化 → ember_eternal 增加
   → 回庇护所继续激活
```
- 激活即时持久化（单次节点激活即存档点，防丢失）。

---

## 6. 边界与异常
1. **ember 不足**：节点锁定，激活请求被拒，提示「深入地窟获取灵烬」。
2. **前置未满足**：依赖节点未激活时不可激活（UI 预禁用）。
3. **循环 / 孤立依赖**：图谱定义时静态校验 DAG，无环；构建期断言。
4. **节点全满**：图谱末端显示「已臻全盛」，无后续（MVP 不扩展）。
5. **存档损坏**：激活记录以增量日志持久化；损坏时回退至上一已知节点集。

## 8. 可访问性
遵循 `docs/accessibility-requirements.md` Basic 级（Lean 强制），矩阵见该文第 2 节。本条落实其 §3.1–§3.5 五项必含项。冲突时以可访问性需求文件分级为权威（该文 §5）。

- **§3.1 形状 + 颜色双编码**：节点已激活暖橙 `#FF8C42` + 外发光，未激活陶土棕 `#A56A43`（美术圣经 §4）；ember 不足用锁形图标 + 灰色（非仅变灰）双编码；灵脉分支用形状/连线区分。
- **§3.2 触控目标 ≥48px（已闭环）**：灵脉图谱节点**视觉直径 44px**（保留视觉语言，美术圣经 §4），但**触控命中区须 ≥48×48px**（透明 padding / 命中半径 48px，见 `docs/accessibility-requirements.md` §3.2「视觉尺寸 vs 命中区」权威澄清），**节点间距 ≥8px** 防热区重叠。以可访问性需求文件 §3.2 为权威（该文已坐实本文件分级优先）。
- **§3.3 色盲安全配色**：节点激活状态以「外发光 + 形状」表达，不依赖橙/棕色差 alone；危险/安全不纯红绿对立。
- **§3.4 非色彩提示**：节点激活采用「点按→弹窗显示效果+消耗→确认」双步防误触；锁定态用锁形图标（非仅变灰）。
- **§3.5 最小可读字号 ≥14px**：节点效果文本 ≥14px、面板标题 ≥18px（美术圣经 §7）。

## 9. 验收标准 + 待工程确认项

1. 节点激活消耗货币正确并即时存档；
2. 前置依赖 / 锁定逻辑正确；
