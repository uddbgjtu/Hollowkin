|---|---|---|

## 1. 一句话定位（Elevator Pitch）

《深窟兽语》是一款**为 PC 桌面单屏打造**的像素风 Roguelike：你扮演一名灵兽驯导者，深入程序生成的地窟层，驯服与组合原创灵兽、构筑流派 Build，死亡后带着元进度回到庇护所永久变强——**给想在一次桌面会话里"轻松上手、构筑上头"的收集策略玩家。**

---

## 2. 设计支柱（Pillars）

**P1 · 桌面一局，策略优先**
> 因此我们会把核心操作收敛到「键盘移动 + 自动普攻 + 键位/鼠标触发技能」，一局可在一次桌面会话内完成；**不做**帧级走位与高频 APM 比拼——这现在是**主动的设计选择**，不再由单手触屏约束推导（ADR-6）。

**P2 · 收集即成长，构筑即策略**
> 因此我们会让每一层的掉落都成为一次"构筑抉择"（带哪只、养哪只、镶什么符文）；**不会**做纯数值线性堆砌的养成，策略深度必须来自组合而非倍率。

**P3 · 死亡不是惩罚，是节奏**
> 因此我们会保证单局能在一段通勤内结束且必带回收益，死亡触发"这次差在哪→补哪条灵脉"的元反思；**不会**让失败感吞噬继续游玩的动机（无硬通货清零、无时间惩罚）。

## 3. MDA 分析

### 3.1 Mechanics（核心机制清单）

| 机制 | 说明 | PC / 原创改造点 |
|---|---|---|
| **移动** | 键盘 8 向移动（WASD / 方向键），角色自动朝向移动方向 | ★ 单屏操控，无虚拟摇杆贴边与握持适配 |
| **战斗** | 自动普攻（最近目标）；手动触发 2–3 个技能（键位 / 鼠标释放，带冷却环） | ★ 非动作走位，强调"何时放技能"而非"如何走位" |
| **灵兽协同** | 队伍携带 1–3 只灵兽，各持技能，自动协战 | ★ 原创"灵兽技能池"，区别于宝可梦战斗指令 / WoW 宠物 |
| **掉落 / 灵囊** ★ | 每层生成：灵兽蛋、符文、消耗品、货币 | ★ "灵囊"：分类栏位（灵兽 / 符文 / 物资）替代 WoW 方格背包，降低桌面端整理负担 |
| **Roguelike 死亡 + 元进度** | 死亡回到庇护所，本次临时构筑清空；部分资源转为永久货币 | ★ "庇护所"元进度中枢，死亡即节奏而非惩罚（P3） |
| **灵脉图谱 / 技能获取** ★ | 永久天赋树 "灵脉图谱"；技能来自灵兽池 + 主角灵脉节点 | ★ 替代 WoW 天赋树，节点为"灵脉"主题、原创命名与布局 |
| **层间抉择** | 每层出口提供 1 选 1–2 的强化 / 招募 / 治疗事件 | 程序生成，驱动构筑多样性 |

### 3.2 Dynamics（涌现玩法行为）

- **构筑抉择循环**：玩家在每层反复权衡"带哪只灵兽、镶什么符文"，形成个人流派偏好（灼烧流 / 召唤流 / 防守反击流等）。
- **死亡反思驱动元投入**：玩家根据"这次卡在第几层、死于什么"决定下一轮灵脉加点，形成长线目标感。
- **低操作偏好涌现**：低 APM 设计使玩家倾向"自动战斗 + 偶尔放技能"的轻策略，Build 设计需服务此习惯（技能高收益、低频率）。
- **图鉴收集正循环**：新灵兽 / 新符文的发现感（Discovery）持续提供重复游玩动机。

### 3.3 Aesthetics（八维趣味主打）

| 维度 | 是否主打 | 理由 |
|---|---|---|
| **Discovery（发现）** | ★ 主打 | 程序生成层 + 新灵兽/符文/事件，桌面会话中最廉价的"新鲜感"来源 |
| **Fantasy（幻想代入）** | ★ 主打 | "驯导者深入地窟、与灵兽结伴"的像素奇幻代入，承接宝可梦式收集幻想 |
| **Expression（自我表达）** | ◐ 次主打 | 流派 Build 与灵脉加点表达策略个性，但深度服务于休闲而非硬核 |
| Challenge / Narrative / Submission / Fellowship | 弱 / 不做 | Challenge 做但非主打（避免硬核劝退）；Narrative 轻量；Submission/Fellowship 在 Lean 阶段不投入 |

**主打结论**：以 **Discovery + Fantasy** 为双引擎，**Expression** 作支撑。这条组合能在最小美术/内容成本下维持桌面 roguelike 的长线可玩性。

## 4. 玩家心理学

### 4.1 目标玩家画像
- **年龄**：18–35 岁
- **设备习惯**：PC 桌面为主设备；一次完整桌面会话；偏好键鼠低 APM、可随时存档中断
- **审美偏好**：像素怀旧、明快饱和配色、萌系剪影
- **经历参照**：玩过宝可梦系列、怪物弹珠、明日方舟、杀戮尖塔、 unlocked 类肉鸽
- **诉求**：轻松上手、策略有深度、收集有成就、单局可在一次会话内完成并可中断

### 4.2 Bartle 玩家类型映射
| 类型 | 服务强度 | 说明 |
|---|---|---|
| **Explorer（探索者）** | ★ 主要 | 发现新灵兽/符文/图层/事件，是核心驱动力 |
| **Achiever（成就者）** | ★ 主要 | 层数进度、图鉴完成度、Build 通关，提供长线目标 |
| Socializer（社交者） | 弱（不做） | Lean 阶段无联机/公会，仅远景异步助战 |
| Killer（杀手） | 不做 | 无 PvP / 竞技，避免竞技挫败劝退 |

> 主导服务 **Explorer + Achiever** 混合画像，符合"收集 + 策略 + 一次会话可完成"的定位。

## 5. 范围分层（优先级标注）

### MVP（Vertical Slice 必须有）
- 键盘移动 + 自动普攻 + 2 个手动技能（键位 / 鼠标）
- 程序生成地窟 **5 层**，每层 1 个精英 + 出口事件
- **5–8 种**原创灵兽（Lean MVP 锁定 **4 只**可驯服入队：苔背 / 焰角 / 霜铃 / 雷隼；权威清单见 `design/gdd/mvp-spirit-bestiary.md` v1.0，其余为 Phase 2+ 扩展）
- 「灵囊」背包（灵兽 / 符文 / 物资 三栏）
- 死亡 → 庇护所元进度（1 条「灵脉图谱」雏形 + 永久货币）
- 基础像素美术：调色板 + 剪影占位

### 拓展（正式版应有）
- 30+ 灵兽、丰富技能池、多流派 Build
- 完整「灵脉图谱」+ 图腾系统
- 事件层 / 商店层 / Boss 层
- 庇护所建造经营（★ 原创改造 WoW 背包经济）
- 图鉴 / 成就 / 每日挑战

### 愿景（长远方向）
- 异步好友助战（轻社交，非实时 PvP）
- 赛季 / rogue-lite 大地图
- UGC 灵兽编辑器 / Mod
- 单机存档强化与可选云同步（PC 内）

## 6. 核心循环

### 6.1 一次 Run 的完整流程
```
[庇护所] 选灵脉配置 / 带初始灵兽
   ↓
[进入地窟层] 程序生成布局 + 事件
   ↓
[探索] 键盘移动 → 发现灵兽蛋 / 符文 / 物资 / 事件
   ↓
[战斗] 自动普攻 + 手动技能 → 灵兽协同
   ↓
[拾取] 灵囊掉落 → 构筑抉择（带/养/镶）
   ↓
[层间抉择] 强化 / 招募 / 治疗（1 选 1–2）
   ↓
[死亡 或 通关该层段]
   ↓
[元进度] 部分资源 → 永久货币 / 灵脉节点 → 回庇护所
   ↓
[下次更深] 依据"差在哪"调整灵脉投入
```

### 6.2 桌面端交互与节奏（贯穿性约束 · ADR-6）
- **操作映射**：WASD / 方向键 8 向移动；鼠标左键点选 + 数字键 / 自定义键位释放 2–3 个技能（外环显示冷却）；普攻全自动；全功能须可纯键盘完成。
- **分辨率**：横屏 **1280×720 @1x**，整数倍缩放护 ADR-4 像素资产（`filter=false`）；窗口可缩放但须整数倍。
- **节奏**：单局 **10–20 分钟**（MVP 5 层），适配一次桌面会话；层间硬存档点仍为唯一存档点（ADR-1）。
- **低操作模式**：保留"自动战斗 + 仅关键技能提示"辅助模式，作为低 APM 设计选择，不再以单手为由。
- **可访问性**：键鼠可操作目标 ≥24×24px + 键位可重映射；形状双编码 / 色盲安全 / 字号 ≥14px 不变（a11y Basic）。

## 7. 视觉锚点（交付美术导演 · Art Director）

> 以下为文字锚点，供美术圣经（Art Bible）对齐；所有参考仅取"风格语言"，不含版权资产。

**像素风格关键词**
- 角色单元 **16×16 / 24×24**；1–2 像素描边；每场景调色板 **≤16 色**
- 轻微抖动（dithering）表现渐变；明快饱和但**不过曝**
- 动画帧率低（4–6 fps 待机/行走），强调"手作像素感"

**色彩情绪板（受宝可梦启发，原创化）**
- 地窟上层：`晨雾青绿 + 暖黄光斑` → 安全 / 好奇
- 地窟中层：`暮紫 + 琥珀` → 神秘 / 紧张
- Boss 深层：`冷靛 + 熔岩橙` → 压迫 / 高潮
- 整体情绪：怀旧温暖中带冒险感，避免阴郁恐怖

**角色与怪物剪影方向**
- ★ 原创"几何萌系"：圆角矩形躯干 + 三角耳/角/尾作特征识别（通用语言，非宝可梦具体轮廓）
- 大头身比（Q 版），表情靠 2–3 像素眉眼变化
- 主角驯导者：小斗篷 + 灵囊挂饰剪影，辨识度高

**可参考风格来源（仅语言）**
- 宝可梦：明快饱和 + 大头萌系剪影 + 场景色块情绪
- PICO-8 / 复古限定调色板：色彩克制与统一
- WoW（仅 UI/图标）：信息密度与装备质感 → 用于「灵囊」与「灵脉图谱」的图标语言（★ 原创改造，不搬图标）
