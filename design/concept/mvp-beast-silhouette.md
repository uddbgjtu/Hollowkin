# MVP 灵兽剪影起步集（Lean Starter）

> **所属项目**：《深窟兽语》/ Hollowkin（工作标题，暂定）
> **用途**：供美术导演尽早跑「几何萌系剪影唯一性审计 + ≤16 色场景子集适配检查」，在 Phase 2 GDD 锁定前排掉最贵的"剪影撞型 / 超色"风险。
> **范围**：MVP（5–8 灵兽）中的 **4 只关键 / 可驯服**灵兽（暂定）。完整 5–8 只留 Phase 2 补。
> **规则来源**：美术圣经 §3 几何萌系骨架（圆角矩形躯干 + 三角耳/角/尾作特征识别）、§4 / §7 形状+颜色双编码（敌我/状态不依赖单一配色）。
> **作者**：文策渊（设计）· v0.1 起步集

---

## A. 主角剪影（参照基准，非灵兽）
- **驯导者**：小斗篷（梯形轮廓）+ 灵囊挂饰（腰侧小袋）+ 圆顶帽。**无**三角耳 / 角 / 尾。
- **作用**：作"人类 / 驯导者"基准。灵兽均带兽耳 / 角 / 尾，天然与主角区分；本集确保灵兽彼此也不撞型。

---

## B. 四只起步灵兽（三角特征种族 ID）
**通用规格**：24×24 像素单元，圆角矩形躯干，大头身比 Q 版，1–2px 描边，主色取自美术圣经三层色彩系统对应层 Hex。

### B1 苔背 Mossback — 坦克 / 前排承伤
- **三角耳**：2 只，朝外上方（outward-up），位于头顶两侧
- **角**：无
- **尾**：圆短尾（**非三角**，作区分轴）
- **配色子集**：上层「晨雾青绿 + 暖黄光斑」（安全 / 好奇）
- **定位**：嘲讽 / 承伤，防守反击流核心
- **辨识点**：双外扩耳 + 无角无尖尾 → 四兽中最"圆润"的轮廓

### B2 焰角 Emberhorn — 火系输出
- **三角耳**：无（或小圆耳，弱化）
- **角**：1 只，居中向前（center-forward），短锐角
- **尾**：1 只尖三角尾，朝右（right）
- **配色子集**：中层「暮紫 + 琥珀」取琥珀 / 橙段
- **定位**：灼烧 DoT 输出，灼烧流核心
- **辨识点**：独角 + 右向尖尾 → 攻击性剪影

### B3 霜铃 Frostling — 控制 / 辅助
- **三角耳**：2 只，朝下（downward），垂耳
- **角**：无
- **尾**：2 只尖三角尾，分叉朝上（split-up）
- **配色子集**：中层「暮紫 + 琥珀」取暮紫段
- **定位**：减速 / 冻结控制
- **辨识点**：垂耳 + 双上分叉尾 → "铃"感轮廓

### B4 雷隼 Voltsprite — 敏捷 / 连击
- **三角耳**：1 只，朝后（back）
- **角**：无
- **尾**：1 只尖三角尾，朝后上方（back-up）
- **额外三角特征**：尖喙（triangle beak）作第四轴
- **配色子集**：上层「暖黄」高亮段
- **定位**：高频连击 / 机动
- **辨识点**：单后耳 + 后上尾 + 尖喙 → 流线型轮廓

## C. 三角特征差异表（剪影唯一性自检）

| 灵兽 | 耳（数 / 向） | 角（数 / 向） | 尾（数 / 向） | 额外三角 | 主色子集 |
|---|---|---|---|---|---|
| 苔背 | 2 / 外上 | 0 | 0（圆） | — | 上层·青绿 |
| 焰角 | 0 | 1 / 中前 | 1 / 右 | — | 中层·琥珀 |
| 霜铃 | 2 / 下 | 0 | 2 / 上分叉 | — | 中层·暮紫 |
| 雷隼 | 1 / 后 | 0 | 1 / 后上 | 尖喙 | 上层·暖黄 |
| 主角 | 0（无兽耳） | 0 | 0 | 斗篷 / 灵囊 | 中性布色 |

**自检结论**：四只灵兽两两之间至少在两个三角轴（耳 / 角 / 尾）上不同，且与主角无兽耳 / 角 / 尾；剪影唯一性自检通过。**最终以美术导演审计为准。**

---

## D. ≤16 色场景子集适配
- 单只灵兽用色 ≤ 所属层 ≤16 色子集的子集（建议单兽 ≤6 主色 + 描边 / 高光）。
- **上层灵兽**（苔背 / 雷隼）共享「晨雾青绿 + 暖黄」母库；**中层灵兽**（焰角 / 霜铃）共享「暮紫 + 琥珀」母库，靠色段（琥珀 vs 暮紫）区分。
- **双编码重点**：焰角（琥珀）与雷隼（暖黄）同属暖色，必须靠「独角右尾」vs「单后耳 + 后上尾 + 尖喙」的**形状差异**区分 → 已满足形状 + 颜色双编码，不依赖配色 alone。
