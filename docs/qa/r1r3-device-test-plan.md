## 2. R1 指标（地窟生成帧预算）

| 指标 | 目标预算 | 测量方法 | 通过判据 | 性质 |
|---|---|---|---|---|
| 单层生成逻辑耗时 | ≤ 1ms | Python 基准复测 + Godot `Time.get_ticks_usec()` | 均值 ≤ 1ms | 沙箱已实测亚毫秒（HIGH 0.0786 / LOW 0.0631 ms/层） |
| 单层渲染（set_cell 批量）均摊 | ≤ 16.6ms | Godot Profiler 帧时间（分步让帧后） | 均摊 ≤ 16.6ms | 【需真机实测】 |
| 渲染尖峰 | < 50ms | 进层峰值帧 Profiler | P95 < 50ms | 【需真机实测】 |
| 保底模板切换 | 不阻断流程 | 注入生成异常路径（GUT） | 回退且无卡死 | 【需真机实测】 |
| 低端机降密度生效 | 房间 / 敌人上限下调 | `OS.get_model_name()` 分支 + 真机帧时间对比 | 低档明显降载 | 【需真机实测】 |
| 同 (seed, floor) 重建一致 | True | 复跑重建布局比对 | 字节一致 | 沙箱已实测 True |

## 3. R3 指标（触屏 + AI 同帧预算）

| 子系统 | 60fps 预算 | 30fps 预算 | 策略 | 真机测量方法 | 性质 |
|---|---|---|---|---|---|
| 输入仲裁（ADR-2 队列） | < 0.5ms | < 1.0ms | 帧末单次结算去重 | 队列 consume 前后 `get_ticks_usec()` 插桩 | 【需真机实测】 |
| AI tick（ADR-3 10Hz） | ~1.66ms | ~3.3ms | 自适应降 5Hz | 单 tick 耗时插桩 + 降频复测 | 【需真机实测】 |
| 实体渲染（同屏 ≤12） | < 4ms | < 8ms | MultiMesh + 离屏剔除 | Profiler draw call / GPU 时间 | 【需真机实测】 |
| 粒子 / 特效 | < 3ms | < 6ms | 低档降密度 | 粒子系统开销插桩 | 【需真机实测】 |
| 合计占帧比（60fps） | < 9.16ms（55%） | — | 余量给主线程 | 各分项求和 | 【需真机实测】 |

> 10Hz 累加器、跨帧率一致性、追帧上限 = 3、自适应降频的**记账逻辑**已在沙箱用 Python 跑通（60fps→99 tick/10s、30fps→200 tick/20s、降频触发、追帧 ≤3 全绿）；本表真机项为上述逻辑的**设备开销实测**，非逻辑验证。
