## 3. Basic 必含项详述（Lean 强制）
> 以下五项为本项目 MVP 验收红线，任何 GDD / 资产 / UI 不得违背。

**3.1 形状 + 颜色双编码（核心）**
- 敌我区分：友方/伙伴 = 上窄下宽"圆润稳定"剪影（盾形/水滴形）；敌方 = 尖锐、不对称、带三角刺/角（锯齿/倒三角）。**不依赖配色 alone**。
- 状态区分（增益 / 减益 / 陷阱 / 可互动物）：一律"轮廓形状 + 色相"双编码——例如减益用三角警示标 + 紫/红，陷阱用锯齿框 + 琥珀，可互动物用圆角高亮 + 青绿。
- 灵兽种族识别：靠**三角特征（耳/角/尾的位置·数量·朝向）**而非仅配色（见 `design/gdd/mvp-spirit-bestiary.md`）。
- 来源：美术圣经 §3（几何萌系）、§4（非色彩提示）、§7（Basic 硬性要求）。

**3.2 键鼠可操作目标（ADR-6 重订，取代原触控 ≥48px）**
- 可点元素点击区域下限 **24×24px**；主操作（技能 / 确认）建议 ≥32×32px；相邻可点元素间距 ≥8px。原「Apple HIT 44pt / Android 48dp / 48×48px 触控命中区」依据随移动端彻底放弃而废止。
- **键盘可达（Basic 必含）**：所有交互须有键盘等价路径（聚焦、方向键遍历、Enter 确认、Esc 返回），且**全键位可重映射**；不得存在「只能鼠标点击」的功能。
- **视觉尺寸**：像素资产维持 ADR-4 整数倍缩放；灵脉图谱节点视觉 44px 可保留，点击区域按本条执行。本文件为分级权威，Wave 2 下游文档须据此对齐。

**3.3 色盲安全配色**
- 危险/安全**不用纯红/纯绿对立**；主调色板经 CVD（红绿/蓝黄/全色盲）模拟验证，确保明暗与色相双重可辨。
- 危险红 `#FF4D4D` 必须配"心形闪烁 / 屏边红框"形状提示；毒/减益用形状而非仅靠 `#A6FF4D` 剧毒绿。来源：美术圣经 §2.2、§7。

**3.4 非色彩提示**
- 低血量：心形图标闪烁 + 屏幕边缘红框脉冲（不只变红）。
- 技能禁用/冷却：置灰 + 锁形图标 + 环形遮罩，不只降低亮度。
- 敌我/可互动物：形状差异优先（见 3.1）。来源：美术圣经 §4、§7。

**3.5 最小可读字号 ≥14px**
- 正文 ≥14px（@1x 逻辑），标题 ≥18px；PC 高 DPI 下按整数倍缩放后物理尺寸达标，禁止非整数缩放导致像素字体发虚（ADR-4）。
- 像素字体须提供 ≥14px 渲染档；长文本支持滚动而非截断。来源：美术圣经 §7。

- [ ] 主菜单/战斗/灵囊/灵脉图谱四处在 CVD 模拟下信息均不丢失。

- [ ] 正文在最小字号档下无截断、可读。
