## 3. 缺失 / 不一致项

- **无方向冲突**：所有规范均指向同一全项目光向，未出现"右下受光""顶光"等矛盾表述。
- **无缺失声明**：四场景均有光向约束；Boss 深层例外已显式声明。
- **唯一遗留（规范 → 执行接口）**：美术圣经 §5 与 `pixel-asset-pipeline.md` §1.3 均明确"该约束作用于 AI 提示词层与人工精修，**不在脚本内自动生成**"。即光向正确性依赖 prompt 约束 + 人工精修 + §6.2 #3 目视复核，当前无自动化校验手段。这属于**人工复核项**，非规范缺失，已在 `pixel-asset-pipeline.md` §5 #4 列为"人工"门禁。
